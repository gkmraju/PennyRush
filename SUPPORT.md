# Support

For bugs and feature requests, use GitHub issues:

https://github.com/royalpinto007/PennyRush/issues

Before opening an issue:

- Search existing issues.
- Use fake financial data in examples.
- Do not include account numbers, statements, receipts, API keys, auth tokens, or personal identifiers.

For security issues, follow [SECURITY.md](SECURITY.md) instead of posting details publicly.
